# Quel spot à Oléron ?

Page qui note de 0 à 10, heure par heure, les spots de surf d'Oléron et de la Côte Sauvage
(Chassiron, Les Huttes, Côte Sauvage) à partir de données gratuites :

- Prévisions de houle, de vent et de marée : Open-Meteo
- Vent mesuré : balises OpenWindMap / Pioupiou (© contributeurs du réseau OpenWindMap)
- Marée mesurée : marégraphe SHOM de La Cotinière

Tout se passe dans le navigateur : aucune clé ni serveur. Les réglages des spots sont dans `SPOTS`, en haut du script de `index.html`.
